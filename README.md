# KINGDOMS

Минимальная одиночная стратегия без сервера. Игра работает в браузере и сохраняет прогресс локально.

## Запуск

### Вариант 1: открыть напрямую
- Откройте `index.html` в браузере.

### Вариант 2: локальный сервер
```bash
cd kingdoms-miniapp
python -m http.server 8000
```

После этого откройте:
```text
http://localhost:8000/
```

### GitHub Pages
- В настройках репозитория откройте `Settings → Pages`.
- Выберите `Deploy from a branch`.
- `Branch: main`, `Folder: /root`.
- Сохраните.
- После деплоя игра будет доступна по ссылке вида:
  `https://<username>.github.io/kingdoms-miniapp/`

## Как играть
- Введите имя правителя.
- Нажмите `Создать партию` или `Войти`.
- На карте 9×9 вы увидите центральную крепость.
- Кликайте по клеткам с ресурсами, чтобы собирать дерево, камень, еду и золото.
- Выбирайте постройку слева и кликайте по свободной клетке, чтобы построить её.
- Все изменения сохраняются локально в браузере.

## Ограничения
- Серверный и сетевой режим не реализованы.
- Для запуска одиночной игры Firebase не требуется.
