# Kingdoms: Crusader

**Версия:** 0.1.0-alpha  
**Статус:** ранний публичный прототип, не полноценная MMO.

Kingdoms — браузерная стратегия о средневековом поселении: строительство, производство ресурсов, развитие замка и карта мира. Интерфейс ориентирован на мобильные устройства и альбомную ориентацию.

## Играть

https://stahij.github.io/kingdoms-miniapp/

## Возможности текущей версии

- Строительство поселения и проверка стоимости зданий.
- Ресурсы, население и базовый экономический цикл.
- Локальное сохранение в браузере.
- Режимы замка и карты мира в клиентском прототипе.
- 3D-рендерер Three.js и модели Kenney Retro Medieval Kit.
- Адаптация интерфейса для телефона.

## Что пока не готово

- Регистрация, безопасная авторизация и постоянные аккаунты.
- Постоянное серверное хранение состояния мира.
- Надёжная синхронизация нескольких игроков и боевые механики.
- Полная замена процедурных построек на готовые 3D-модели.
- Проверка производительности на широком наборе устройств.

Сетевые функции в `server.js` — экспериментальная основа, а не готовый продакшен-сервер. Не используйте её как источник постоянного игрового состояния.

## Запуск локально

Требуется Node.js 18 или новее.

```bash
npm install
npm test
npm start
```

Затем откройте http://localhost:3000/.

Статическую клиентскую часть можно также открыть через любой статический HTTP-сервер из каталога репозитория. Для корректной работы сетевых функций нужен запущенный Node.js-сервер.

## Структура проекта

```
public/
  index.html          интерфейс игры
  game.js             состояние, ввод и игровая логика
  economy.js          экономика и правила строительства
  three-renderer.js   3D-сцена Three.js
  assets/kenney/      модели и лицензия ассетов
server.js             экспериментальный Socket.IO-сервер
index.html            переход на public/index.html для GitHub Pages
scripts/check.js      базовые проверки проекта
.github/workflows/    CI и утилиты сопровождения
```

## Ассеты

Модели Kenney хранятся в `public/assets/kenney/Models/GLB format/`. Лицензионные условия см. в [License.txt](public/assets/kenney/License.txt). Three.js и GLTFLoader загружаются с CDN, поэтому для этой версии требуется интернет.

## Проверки

`npm test` проверяет синтаксис JavaScript и наличие ключевых файлов, на которые ссылается клиент. GitHub Actions запускает эти проверки при push и pull request.

## Первый релиз

Рекомендуемая версия: **0.1.0-alpha**. Это релиз для раннего тестирования, а не заявление о завершённой MMO. Перед полноценным релизом необходимо пройти ручную проверку строительства, сохранения, мобильной ориентации и загрузки 3D-ассетов.
