KINGDOMS — одиночный режим без сервера
======================================

Что внутри:
- одиночная игра с картой 9×9;
- центральная крепость в центре карты;
- ресурсы: дерево, камень, еда и золото;
- добыча ресурсов по клику по клеткам;
- строительство лесопилки, каменоломни, фермы и казарм;
- проверка стоимости и доступных ресурсов;
- локальное сохранение в localStorage;
- возврат в меню и новая игра;
- без Firebase и без серверных зависимостей.

Запуск:
1. Скачайте или клонируйте репозиторий.
2. Откройте папку проекта и запустите статический сервер или просто откройте index.html в браузере.
3. Для локального запуска в терминале:
   python -m http.server 8000
   Затем откройте http://localhost:8000/

GitHub Pages:
1. В репозитории откройте Settings → Pages.
2. Source выберите «Deploy from a branch».
3. Branch: main, folder: / (root).
4. Сохраните.
5. Сайт будет доступен по адресу вида: https://<username>.github.io/kingdoms-miniapp/

Важно:
- этот проект не требует Firebase;
- сетевой режим не реализован и не обязателен для запуска одиночного режима;
- всё состояние хранится локально в браузере.
