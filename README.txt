KINGDOMS — СЕТЕВОЙ MVP ДЛЯ 5 ИГРОКОВ
====================================

В комплекте index.html, style.css, game.js. Загрузить их в корень GitHub-репозитория вместо старых файлов. GitHub Pages — только хостинг сайта; для совместной игры обязательно настроить Firebase.

Возможности MVP:
- комнаты до 5 игроков, вход по 5-значному коду;
- личная крепость 9×9 клеток;
- строительство лесопилки, каменоломни, фермы, пекарни, казарм, стены и рынка;
- производство дерева, камня, еды, золота;
- жители, набор пехоты, рейды и добыча ресурсов;
- изменения в комнате передаются другим игрокам через Firebase Realtime Database.

1. СОЗДАЙ FIREBASE-ПРОЕКТ
Открой https://console.firebase.google.com/ → Create project. Затем в настройках проекта → General → Your apps добавь Web app (значок </>) и сохрани значения apiKey, authDomain, projectId, appId.

2. ВКЛЮЧИ АНОНИМНЫЙ ВХОД
Build → Authentication → Get started → Sign-in method → Anonymous → Enable → Save.

3. СОЗДАЙ REALTIME DATABASE
Build → Realtime Database → Create Database. После создания скопируй URL базы (он показан вверху страницы). Вкладка Rules: для теста замени правила на следующие и нажми Publish:

{
  "rules": {
    "rooms": {
      "$room": {
        ".read": "auth != null",
        ".write": "auth != null"
      }
    }
  }
}

ВАЖНО: это открытые тестовые правила для MVP. Любой анонимно вошедший пользователь потенциально может менять данные комнат. Не добавляй платежи или личные данные. Перед публичным запуском правила и проверку действий нужно усилить.

4. ДОБАВЬ FIREBASE-КОНФИГ В ИГРУ
В GitHub открой game.js → Edit (карандаш). В начале файла найди firebaseConfig и замени заглушки на реальные значения из Firebase:
apiKey, authDomain, databaseURL, projectId, appId.
Для databaseURL вставь точный URL Realtime Database из консоли Firebase. Сохрани через Commit changes.

5. ОТКРОЙ ИГРУ
Через 1–3 минуты открой https://stahij.github.io/kingdoms-miniapp/
Первый игрок нажимает «Создать партию» и отправляет друзьям код. Остальные вводят код и нажимают «Войти». Каждый игрок должен открыть игру на своём устройстве/сеансе браузера.

УПРАВЛЕНИЕ
Выбери здание, затем свободную клетку. Производство начисляется, пока игрок находится в игре. Для найма пехоты построй казармы. Выбери соперника и отправь рейд.

ОГРАНИЧЕНИЯ
Это первый MVP, а не законченная MMO. Экономика обновляется клиентами, бои упрощены, защита от читерства пока слабая, нет постоянной регистрации и восстановления аккаунта. Комнаты рассчитаны максимум на 5 игроков.
